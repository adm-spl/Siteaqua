# Fotos

Uma pasta por zona. Coloca aqui os ficheiros originais; o Astro gera os tamanhos e formatos otimizados no build.

| Pasta | Conteúdo |
|---|---|
| `home/` | hero da página inicial (`hero.jpg`) e fotos gerais |
| `t2-jardim/`, `suite/`, `t2-terraco/` | uma pasta por unidade (o nome é o `unitId`) |
| `regiao/` | termas, montanhas, gastronomia |
| `atividades/` | trilhos, canyoning, kayak |

**Regras**
- JPG (ou PNG se tiver transparência), lado maior entre 2000 e 3000 px, idealmente < 3 MB cada.
- Nomes em minúsculas, sem espaços nem acentos, descritivos: `sala-01.jpg`, `quarto-casal.jpg`, `terraco-vista.jpg`. O número define a ordem.
- A primeira foto de cada unidade (`01-...`) é a capa.
- Só fotos de que tens os direitos (próprias ou de fotógrafo com autorização). Evitar bancos de imagens que não sejam das unidades reais.
- Texto alternativo (descrição de cada foto) escreve-se depois, comigo, em PT e EN.
